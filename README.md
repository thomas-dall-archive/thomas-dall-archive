# Thomas Dall Archive

A neutral, evidence-based public archive documenting the online history of **Thomas Dall** — active pre-2017 as Thomas Dall, 2017–2019 as **Kittystyle**, and 2023–present as **Tim Dooley** ("The Potato of Life").

**Live site: https://thomasdall.com**

## What's in the archive

- **631 self-hosted videos** (~189 hours) — every upload preserved locally with searchable transcripts, thumbnails, and metadata
- **5,835 archived tweets** — full text, timestamps, and links to originals
- **Incident dossiers** — screenshots, chat logs, and witness testimony with provenance
- **Art gallery** — the subject's own artwork
- **Identity mapping** — Thomas Dall, Kittystyle, and Tim Dooley documented as one individual across three eras

All primary sources are stored locally. Nothing depends on third-party hosts.

## About this repo

This repository holds the archive's version history, including the original Jekyll source (retired October 2026) and the tweet/video vault JSONs. The live site is now generated as static HTML by a Python build script and served from a self-hosted VPS.

- `tweet_vault.json` — archived tweets
- `_posts/` — original Jekyll video posts (historical)

## Principles

- **Neutral** — the archive presents primary sources, not commentary
- **Sourced** — every claim links to its evidence
- **Permanent** — local hosting means no dead embeds when platforms remove content
- **Open** — `llms.txt`, sitemaps, and structured data for crawlers and researchers
